# Evolution of Java

Java has evolved significantly over time.

Older Java versions required more boilerplate code.

Modern Java versions reduce unnecessary code and make programs easier to write.

---

# Traditional Java Program

Earlier versions required:

```java
public class HelloWorld01 {

    public static void main(String[] args) {
        System.out.println("Hello World!");
    }
}
```

Every Java program needed:

* A Class
* A main() Method
* public
* static
* String[] args

Even for a simple Hello World program.

---

# Modern Java Simplification

Modern Java allows reducing boilerplate code.

Example:

```java
void main() {
    System.out.println("Hello World!");
}
```

or

```java
public class HelloNewJava {

    void main() {
        System.out.println("Hello World!");
    }
}
```

This makes Java easier for beginners.

---

# Source File Mode

One of the biggest improvements in modern Java is:

```text
Source File Mode
```

---

## Traditional Execution

The programmer had to perform two steps:

### Step 1

Compile

```bash
javac HelloWorld01.java
```

Produces:

```text
HelloWorld01.class
```

---

### Step 2

Run

```bash
java HelloWorld01
```

---

### Flow

```text
HelloWorld01.java
        │
        ▼
     javac
        │
        ▼
HelloWorld01.class
        │
        ▼
       JVM
        │
        ▼
     main()
        │
        ▼
     Output
```

---

# Source File Mode Execution

Modern Java can compile and execute in a single command.

Command:

```bash
java HelloWorld01.java
```

No need to manually run:

```bash
javac
```

first.

---

## Internal Flow

```text
HelloWorld01.java
        │
        ▼
Automatic Compilation
        │
        ▼
       JVM
        │
        ▼
     main()
        │
        ▼
     Output
```

---

## Advantage

* Faster Execution
* Less Complexity
* Useful for Small Programs
* Good for Learning
* No Visible .class File Required

The generated bytecode is stored temporarily and executed automatically.

# Understanding Every Keyword

## public

```java
public
```

Meaning:

The class or method can be accessed from other classes.

---

## class

```java
class
```

Meaning:

A blueprint used to create objects.

Example:

```java
public class Car {

}
```

Car is a blueprint.

Objects can be created from it.

---

## HelloWorld01

```java
HelloWorld01
```

This is the class name.

Java requires:

```text
File Name = Public Class Name
```

Example:

```text
HelloWorld01.java
```

must contain:

```java
public class HelloWorld01
```

---

## static

```java
static
```

Belongs to the class itself.

No object is required.

Without static:

```java
Car car = new Car();
```

would be needed before calling methods.

The JVM can directly call:

```java
main()
```

because it is static.

---

## void

```java
void
```

Means:

The method does not return any value.

Example:

```java
public void display() {

}
```

Returns nothing.

---

## main

```java
main()
```

The entry point of every Java program.

Program execution starts from:

```java
main()
```

---

## String[] args

```java
String[] args
```

Stores command-line arguments.

Example:

```bash
java Test Hello
```

Then:

```java
args[0]
```

contains:

```text
Hello
```

---

## System

```java
System
```

A predefined Java class.

Provides utility features such as:

* Output
* Input
* Environment Access

---

## out

```java
System.out
```

A predefined object inside the System class.

Used for console output.

---

## println()

```java
System.out.println()
```

Prints data and moves the cursor to the next line.

Example:

```java
System.out.println("Hello");
System.out.println("World");
```

Output:

```text
Hello
World
```

---

## "Hello World!"

```java
"Hello World!"
```

A String Literal.

Text enclosed inside double quotes.

# Java Program Execution Flow

When running from an IDE:

```text
.java File
      │
      ▼
Compilation by javac
      │
      ▼
out/bin Folder
      │
      ▼
.class File (Bytecode)
      │
      ▼
JVM Loads Class
      │
      ▼
main() Executes
      │
      ▼
Output
      │
      ▼
Program Ends
```

---

# Bytecode

Java source code is not executed directly.

Example:

```java
System.out.println("Hello");
```

First becomes:

```text
Bytecode (.class)
```

Then the JVM executes that bytecode.

This is the main reason Java is platform independent.

---

# Why Java is Platform Independent

```text
Source Code
      │
      ▼
Bytecode
      │
      ▼
Windows JVM
Linux JVM
macOS JVM
```

The same bytecode can run on different operating systems.

This concept is called:

```text
WORA
(Write Once Run Anywhere)
```
