# 🎤 Java Fundamentals — Interview Questions

> Important Java Fundamentals interview questions arranged by **practical interview priority**.
>
> Priority is based on commonly recurring Java interview topics and actual interview experiences.

---

# 🔴 Priority 1 — Most Asked / Must Prepare

> These are the questions you should prepare **very well**.
>
> Interviewers commonly ask these directly or use them as follow-up questions.

### 1. What is Java?

### 2. Why is Java platform-independent?

### 3. What is JVM?

### 4. What is JDK?

### 5. What is JRE?

### 6. Explain the relationship between JDK, JRE, and JVM.

### 7. What is Bytecode?

### 8. Explain the Java program execution flow.

### 9. What happens when you compile a Java program using `javac`?

### 10. What happens when you run a Java program using the `java` command?

### 11. What is the difference between `java` and `javac`?

### 12. Is Java a compiled language or an interpreted language?

### 13. Is JVM platform-independent?

### 14. Why is JVM platform-dependent if Java is platform-independent?

### 15. What does WORA (Write Once, Run Anywhere) mean?

### 17. What are the main applications of Java?

### 21. Is Bytecode the same as machine code?

### 22. Why is Java popular for backend and enterprise applications?

### 24. Why is Java not considered a purely object-oriented language?

### 29. Who created Java?
