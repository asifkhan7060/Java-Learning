## 🤔 What is Java?

Java is a high-level, class-based, object-oriented programming language designed to be portable and suitable for developing applications ranging from small programs to large-scale enterprise systems.

Java follows the principle:

> **Write Once, Run Anywhere (WORA)**

Java is widely used for backend, enterprise, cloud, Android and other types of applications.

---

## ❓ Why Java?

Java became popular because of features such as:

- **Platform Independence** — Java programs can run on different platforms through the JVM.
- **Object-Oriented** — Supports encapsulation, inheritance, polymorphism and abstraction.
- **Robust** — Strong type checking, exception handling and automatic memory management.
- **Multithreaded** — Provides built-in support for concurrent programming.
- **Large Ecosystem** — Has a mature collection of libraries, frameworks and development tools.

## 🏛️ Java Editions

### Java SE — Standard Edition

Provides the foundation of Java programming.

Includes areas such as:

- Core language features
- OOP
- Collections
- Exception Handling
- Multithreading
- I/O
- Networking

> **This is the main platform for learning Core Java.**

### Jakarta EE — Enterprise Edition

Previously known as **Java EE**.

Provides specifications and APIs for enterprise application development.

Examples include:

- Servlets
- JSP
- Enterprise components
- Persistence
- Web services

### Java ME — Micro Edition

Designed for:

- Embedded devices
- Resource-constrained devices
- Earlier generations of mobile devices

It is less common in mainstream Java development today.

---

## 🔑 Key Points

- Java was created at **Sun Microsystems**.
- **James Gosling** is commonly known as the father of Java.
- The original project was called **Oak**.
- Java was publicly introduced in **1995**.
- Java is **platform-independent** at the bytecode level.
- Java is **not the same as JavaScript**.
- Java SE is the foundation for **Core Java**.
- Java EE was later renamed **Jakarta EE**.
